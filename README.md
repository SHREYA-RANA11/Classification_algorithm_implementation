# Machine Learning Classification Algorithms

This repository contains implementations of popular Machine Learning classification algorithms using Python and Scikit-learn.

## Algorithms Implemented

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes

## Concepts Covered

- Data Preprocessing
- Train-Test Split
- Feature Scaling
- Model Training
- Model Evaluation
- Accuracy Score
- Confusion Matrix

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure

```bash
classification-algorithms/
│
├── Logistic_Regression.ipynb
├── KNN_Classification.ipynb
├── Naive_Bayes.ipynb
├── datasets/
└── README.md
```

## Learning Objective

The objective of this repository is to understand the implementation and working of Machine Learning classification algorithms through practical examples.

## How to Run

1. Clone the repository

```bash
git clone https://github.com/SHREYA-RANA11/Classification_algorithm_implementation.git
```

2. Navigate to the project folder

```bash
cd Classification_algorithm_implementation
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the Jupyter notebooks
